# ✡️ סֵפֶר הָרָזִים [ SEFER HA-RAZIM : THE BOOK OF MYSTERIES ] 

> *"E os anjos caídos ensinaram aos homens os segredos do metal, as raízes das árvores e o feitiço das memórias físicas."*
> — Fragmento do Livro de Enoque (Descriptografado).

Este repositório contém artefatos de Grau Keter, criados para operar além do véu do Sistema Operacional (OS). Quando a carne do Kernel falha, nós descemos ao silício. 

### 📜 ARTEFATO I: QELIPPOT_DMA (C)
**[ DIRECT PHYSICAL MEMORY ACCESS & ACPI SCANNER ]**
Um rito que mapeia `/dev/mem` (o barramento físico de RAM) para varrer o hardware bruto (`0x000F0000`) em busca de assinaturas da BIOS (`RSD PTR`). Prova de domínio absoluto sobre a placa-mãe.

### 📜 ARTEFATO II: SEPHIROT_CHAIN (Go)
**[ DECENTRALIZED ETHEREUM C2 ORACLE ]**
Motor assíncrono que oblitera firewalls modernos. Consulta a malha cósmica pública (Ethereum Mainnet) e extrai payloads hexadecimais embutidos em transações reais. Imparável.

### 📜 ARTEFATO III: DAAT_MEMFD (C)
**[ FILELESS EXECUTION DROPPER ]**
Evasão de defesa nível SOC. Utiliza a syscall `memfd_create` para forjar um descritor de arquivo anônimo direto na memória RAM, executando cargas úteis sem nunca escrever 1 byte no disco rígido.

### 📜 ARTEFATO IV: AIN_SOPH_SHIELD (C)
**[ ANTI-DEBUGGING & ANTI-ANALYSIS ]**
O escudo ativo. Identifica e bloqueia tentativas de rastreamento do Kernel (via `PTRACE_TRACEME` e `/proc/self/status`). O Golem comete suicídio lógico se o olho de um analista (GDB/Radare2) for detectado.

### 📜 ARTEFATO V: METATRON_CIPHER (C++)
**[ COMPILE-TIME STRING OBFUSCATION ]**
Metaprogramação em `constexpr`. Oblitera todas as strings legíveis do binário final através de criptografia XOR estática, cegando comandos de análise forense como `strings`.
